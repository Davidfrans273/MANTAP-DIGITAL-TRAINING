# 🔐 Login & Signup System

A simple Login & Signup authentication system built with PHP and MySQL. This project allows users to create an account, log in securely, and access a protected page using session-based authentication.

## ✨ Features

- User Registration (Sign Up)
- User Login
- Session Authentication
- Form Validation
- MySQL Database Integration
- Responsive Interface with Bootstrap

## 🛠️ Built With

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap 5

## 📁 Project Structure

```
├── config/
│   └── koneksi.php
├── index.php
├── login.php
├── signup.php
├── logout.php
├── style.css
└── database.sql
```

> *Folder structure may vary depending on your project.*

## 🚀 Getting Started

1. Clone this repository.
2. Move the project to your web server directory (e.g. `htdocs` for XAMPP or `www` for Laragon).
3. Create a MySQL database.
4. Import the `database.sql` file.
5. Update the database configuration in `config/koneksi.php`.
6. Start Apache and MySQL.
7. Open the project in your browser.
